# Rust計画のグリル

**テーマ**: $ARGUMENTS

`Skill(grill-me)` をテーマ（と対象パス）を引数に呼び出し、共通認識に達するまで議論する。実装・コード変更はせず、決定事項をまとめるところまで（実装は `/impl-rust` に引き継ぐ）。困りごとが起点のときは表面の症状ではなく根本原因を論点にする。既存バグを見つけたらその場で深追いせず `/thought-bug` を提案する。

全論点で合意に達したら、決定事項をMarkdownファイル（カレントディレクトリ直下）に書き出す。冒頭に `date '+%Y-%m-%d %H:%M:%S'` で取得した設計時刻、調査対象・概要・結論・合意した設計と理由・実装に必要な調査結果（`ファイル名:行番号` 根拠）・参照すべきパス・未解決点を含め、`/impl-rust` にそのまま渡せる形にする（実装方針は`rust-coder`準拠が前提）。この仕様書はtemporaryな一時agent指示ファイルであり、時間経過で実態と乖離しうる旨を明記する。
